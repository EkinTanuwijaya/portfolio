# Ekin Tanuwijaya — Portfolio

React, TypeScript, Vite, and plain CSS. Content is based on the supplied 2026 CV. Samsung contributions are grouped under the corresponding employment role, followed by education, skills, and contact information.

## Development

```sh
npm install
npm run dev
```

## Validation and production

```sh
npm test
npm run build
npm run preview
```

Edit portfolio content in `src/main.tsx` and design in `src/style.css`. The downloadable résumé lives in `public/`. Google Fonts are optional; system fonts remain available when offline. Update employment dates when they change.
